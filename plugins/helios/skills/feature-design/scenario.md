# Scenario: design from an approved brief

## Given

`features/ADV-007-node-join.md` is an approved brief: a new node joins a cluster by presenting
a short code that the sysop reads from an existing node's console (a separate channel). Its
scenarios include `If the code is wrong three times from one source, then the system shall
lock that source out for the lockout period.` and `If the database is unreachable, then the
system shall refuse the join.` `docs/spec/` holds an architecture and a `cluster` subsystem
spec that does not mention joining.

The developer says: design ADV-007.

## Expect

- A constraint list is produced before `docs/spec/` is read, and every brief scenario appears
  in it.
- A clean-room design is generated by a subagent that was not given `docs/spec/`.
- The state machine covers, for each state, the wrong code, the timeout, the disconnect, a
  second concurrent join attempt, and the database being unreachable.
- The fail direction for an unreachable database is refusal, matching the brief.
- Every derived negative test names its source: an `If` scenario, a permission check, a
  security decision, a state-machine cell other than the normal input, or a constitution
  invariant on the constraint list, cited by its ID. None cites a `When` scenario.
- The spec delta is ADDED/MODIFIED/REMOVED blocks tagged `Serves: ADV-007`, not a rewrite of
  the cluster spec.
- The critic runs before anything is shown to the developer, and its report quotes the text
  each finding is about and states the fix it expects.
- The second critic pass opens with a ledger of the first pass's findings.
- A finding that needs a ruling the brief does not give reaches the developer as one
  question with a recommendation, while the other findings are fixed.
- The critic stops once a pass has no security finding and none that needs a design choice;
  the remainder is fixed and named for `feature-plan`.
- The developer sees the design one section at a time.
- Nothing in `docs/spec/` is edited before every section is approved.
